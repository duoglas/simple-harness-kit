方案

SHK 做了一件事: 用 Hook 强制流程

不是提示词建议，不是最佳实践文档 — 是钩子脚本在每次工具调用时自动检查。

1
PLAN — 暂停等确认，不可逆操作列明
2
EXECUTE — 独立 Agent 实现，TDD
3
VERIFY — 量化证据，不是"看起来行了"
4
REVIEW — 独立 Agent 审查，不是作者自审
5
FEEDBACK — 出事 → 写约束 → 下轮自动遵守

关键区别

Cursor Rules / .cursorrules — 放提示词，AI 可以忽略
CLAUDE.md — 放指令，长 session 后会退化
SHK Hook — 放脚本，每次工具调用都执行，跳不过

机制

越用越强: 约束累积

每次出事，不是"修了就完了" —
而是走一个 5 步流程:

F1  原样记录问题
F2  判断问题属于哪个层级
F3  提炼成通用规则 (不是 "把 X 改成 Y")
F4  写入 constraints.md，分配 C-ID
F5  Agent 按约束 ID 修复

下一轮 PLAN 自动读取所有约束。
同类问题不需要人记住，系统记住了。
